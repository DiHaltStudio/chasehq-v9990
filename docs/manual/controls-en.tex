\textbf{Notes.}
\begin{itemize}
\item Each press of \textbf{GEAR} changes between the low gear, \texttt{LO}, and the high gear, \texttt{HI}. Start in \texttt{LO} and change to \texttt{HI} when the speed stops rising.
\item The \textbf{turbo} gives a burst of speed for a few seconds. You have \textbf{three per stage}; the icons at the bottom left show how many are left.
\item \key{P} pauses the game and silences it. Press any control to go on.
\item \key{Q} ends the game at once, as if the time had run out with no credits left.
\item Pressing left and right, or accelerate and brake, at the same time does nothing.
\end{itemize}
